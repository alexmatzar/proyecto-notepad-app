# Bloc de Notas Online

Proyecto final desarrollado con Angular y Firebase Realtime Database usando REST API

## Tecnologías utilizadas

- Angular 17
- TypeScript
- Firebase Realtime Database
- Angular Router
- HttpClient
- CSS

## Funcionalidades

- Crear notas
- Editar notas
- Eliminar notas
- Listado de notas
- Editor de texto
- Responsive design

## Instalación

```bash
npm install
```

## Ejecutar proyecto

```bash
ng serve
```

## Firebase

El proyecto utiliza Firebase Realtime Database mediante REST API sin usar Firebase SDK ni AngularFire.
