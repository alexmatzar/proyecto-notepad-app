# Bloc de notas online

Proyecto final desarrollado con angular y firebase realtime database usando REST API

## Tecnologías

- Angular 17
- TypeScript
- Firebase realtime database
- Angular Router
- HttpClient
- CSS

## Funcionalidades

- Crear notas
- Editarlas
- Eliminarlas
- Listarlas
- Editor de texto
- Responsive design

## Instalación

```bash
npm install
```

## Ejecutar proyecto

```bash
ng serve
```

## Firebase

El proyecto usa firebase realtime database mediante REST API sin usar firebaseSDK ni angularfire.
